## ♟️ Opening: who I am

I like data best when it's boring: clean, tested and on time. Getting it there is the fun part.

I work across the whole chain, from ingestion and modelling to the dashboard someone actually opens on Monday morning, and more recently LLM agents that let people ask their data questions in plain language.

```sql
SELECT 'Data Analyst / Data Engineer'                  AS role,
       'Toulouse, France'                              AS based_in,
       'Master MIAGE, Université Toulouse III'         AS education,
       'Pipelines, dashboards and LLM agents'          AS focus
FROM   oussama
WHERE  data_quality = 'tested';
```

Away from the keyboard: chess, poker and long runs. All three are about making good decisions with incomplete information, which is most of data work too.
